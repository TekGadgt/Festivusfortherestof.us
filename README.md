# Festivus for the Rest of Us!

**A Festivus miracle! A website dedicated to the greatest holiday ever invented by Frank Costanza.**

This is quite possibly one of the simplest sites on the internet -- and one of my oldest still standing. It does exactly one thing: tells you how long until Festivus (December 23rd). That's it. No frameworks, no build steps, no npm install. Just vibes and a Festivus pole.

## What It Does

- **It's not Festivus yet?** Upset Jerry flanks a live countdown timer ticking away the months, days, hours, minutes, and seconds until December 23rd. The favicon frowns. We all frown.
- **IT'S FESTIVUS!** Happy Jerry appears! The page celebrates! The favicon rejoices! Time for the Airing of Grievances and the Feats of Strength!
- **Festivus is over?** The site mourns and starts looking ahead to next year.

## The Stack

The aluminum pole of web development:

- One `index.html` file
- Bootstrap (for centering a div, as is tradition)
- Moment.js (for the countdown math)
- Two Jerrys (happy and upset)
- One Festivus pole (aluminum, obviously -- tinsel is too distracting)

## Run It

Open `index.html` in a browser. That's it. I told you it was simple.
